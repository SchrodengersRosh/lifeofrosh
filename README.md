# Roshan, Run of Show

Personal portfolio for Roshan. Built with Next.js 16, TypeScript, Tailwind CSS v4.

## Development

```bash
npm run dev    # start dev server
npm run build  # production build
npm run lint   # lint check
```

## Architecture

- `/` : Run of Show homepage
- `/work/[slug]` : Case studies
- `/life` : Personal page
